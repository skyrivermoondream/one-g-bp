# ONE-G BP

ONE-G 具身智能开发与应用平台。中英文交互式商业计划书，包含 7 页正文，以及封面、章节导览和结束页。

## 查看

通过本仓库的 GitHub Pages 站点打开，或完整下载仓库后用浏览器打开 `index.html`。请保留 `assets` 目录。

支持中英文、深浅主题、全屏、图片放大及视频演示。外部网站和文献链接需要联网。
